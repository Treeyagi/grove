# Grove docs

These docs follow [Diataxis](https://diataxis.fr): four kinds of page, each answering one kind of question.
A page serves exactly one of the four and doesn't drift into the others.

| Folder | Answers | Pages |
|---|---|---|
| `tutorials/` | "Teach me by doing" | *(empty — nothing here needs a hand-held walkthrough yet)* |
| `how-to/` | "How do I do this specific job?" | [run-checks](how-to/run-checks.md), [release](how-to/release.md) |
| `reference/` | "What exactly is X?" | [code-map](reference/code-map.md), [config](reference/config.md) |
| `explanation/` | "Why does it work this way?" | [gotchas](explanation/gotchas.md) |

Broader context — how Grove is built and the decisions behind it — is in [ARCHITECTURE.md](../ARCHITECTURE.md).

When you learn something new about Grove, add it to the quadrant that matches the question it answers,
rather than to `CLAUDE.md`.
